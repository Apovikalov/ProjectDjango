ProjectDjango - проект интернет-магазина, созданный на языке Python с использованием фреймворка Django.

Создано приложение под названием catalog, в котором с помощью HTML и Bootstrap созданы две страницы - 
Home (главная) и Contacts (контакты). Для этих страниц, а также для самого приложения, созданы контроллеры.
